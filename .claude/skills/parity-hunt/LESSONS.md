# Parity lessons

Lessons from past parity hunts and cross-engine changes. Read this when hunting a TS/GPU divergence or before landing a change that touches both engines.
Each entry's slug in parentheses names the original memory, archived under `.claude/scratchpad/memory-archive-2026-09-23/`; open it for the full incident.

## Control flow and evaluation order

- **Spell each adder's class membership explicitly** (adders-after-a-class-table) — TS appended adders to ONE arm of a class ternary while the GPU added them after the whole class table, so a naval unit got land-only heals on one engine. Take each adder's domain clause from the XML, write `naval ? 0 : x` on both sides, and pin new strength/heal terms with a test asserting every function calling the sibling adder (`congressUnitCS` / `_congress_unit_cs`) also calls the new one.
- **Keep a guard's early return as its own arm when vectorising** (clamp-is-not-an-early-return) — `if (have >= need) return` ported as `min(need, ...)` drags an OVER-cap value down; the two agree until an unclamped writer pushes a value past the cap. Write `torch.where(held, xp, torch.minimum(need, xp + gain))` and ask what can put the value outside the guarded range.
- **Assert that parallel GPU arms cover the TS chain exactly once** (disjoint-arms-exhaustiveness) — a TS if/else chain always runs a branch; independent GPU boolean arms can leave a mask-legal action in no arm, a silent no-op visible only as a later rng split. Put the truth table (occupants x city x attacker class) in a poke and suspect arms built from another arm's negation.
- **Make a catalog-keyed `default:` throw** (switch-default-hides-a-fork) — a TS switch whose `default:` is a real case swallows every new catalog row, while the GPU's fallback picks something else. Give every row an explicit arm and grep both engines' keyed switches when a row is added.
- **Sort a TS record walk into the GPU's index order** (insertion-order-is-a-fork) — `Object.entries` runs in insertion order, the GPU's nested pair loop in index order; they fork once two records touch one capped or clamped quantity in the same pass. Sort the TS side by `(a, b)` or prove no iteration reads another's write.
- **Tick per record where the TS loop does** (phase-end-batch-tick) — a GPU phase that decrements every clock once at the end forks from a TS loop that ticks each record after its own step, when a record expiring mid-loop frees state a later record reads (storm walk, 9222 t181). Check whether any later iteration reads the ticked field.
- **Put a mid-turn grant on the same side of every per-turn charge** (grant-lands-in-a-phase-order) — TS completed techs then charged upkeep, the GPU the reverse, so a granted Spy cost gold a turn apart; a founding grant ran before the settler was cleared and found its tile taken. When a row creates or destroys something mid-turn, list the charges and occupancy reads of that collection and order them identically.
- **Have a shared body RETURN the amount, not write the store** (callee-write-shadowed-by-local) — `recruit` added to `owner.gpp[cls]` while its caller held the same value in a local and wrote it back, undoing the refund on TS only; direct-call tests passed. Grep callers for a local plus an `owner.X = local` writeback before adding a store write in a shared body.

## Legality, refusals and the driver

- **Carry the whole TS validator into a GPU applier arm** (applier-carries-whole-validator) — an arm that checks only its row's clause drops the validator's shared early returns (water, resource), so a driven Monastery on Coast was built on the GPU and refused on TS. Put the early returns in one shared predicate ANDed by mask and applier, count every reader of a legality constant, and make whichever engine applies a driven decision re-check every predicate the candidate row used.
- **Port the refusal, not just the write, across a plane split** (split-state-refusal-parity) — TS keeps one tile map, the GPU splits the fact over several planes, so a lone GPU check sees a fraction of what TS refuses; and TS sets the field differently per seat class. Enumerate every GPU plane carrying the fact and verify per seat which ones TS actually writes.
- **Gate target legality on "is there a city here"** (target-legality-gates) — gating only the attack mask turns a forbidden assault into a no-op instead of falling through to the garrison, because city-first precedence reads the same predicate. These forks surface in `rng` or `warWeariness`, never a combat column; barbarians stay always-hostile.
- **Mirror the driver's compared tables clause by clause** (driver-twin-mirrors-mask) — jobs, spreads, buys and routes are computed by both `policy/drive.py` and `cpu/driver/driver.ts`, and an approximate twin (a blanket `!isWater`, a missing taken-job mask) matches until a trajectory reaches the gap. Diff the twin against the mask body it mirrors and change both files together.
- **Check common-vocabulary gates against a chassis that lacks the vocabulary** (zero-mp-chassis) — TS skipped any unit with `movesLeft <= 0`, silencing the Spy (moves 0 by design) while the GPU applied its verbs. When a roster row makes a new unit or verb reachable, expect the first serve to expose it, and read movement/attack/charge gates for chassis that have none.

## Representation mismatches between the engines

- **Print both row sets before reading either body** (free-seat-walks) — TS `state.seats` excludes the Free Cities, the GPU's every-row walk includes `FREE_ROW`; `isTerritorial` covers `FREE_SEAT` where `< BARB_SEAT` does not, and per-major planes have no free row to index. Decide the set from Civ 6, make both engines name it, and grep writes the wider reach enables.
- **Decode a direction with `neighborTile(map, t, d)`** (compacted-list-shifts-directions) — TS `neighbors()` drops off-map slots while the GPU `neigh` plane keeps -1, so indexing the list by direction shifts at the map edge. Grep `neighbors(...)[` at every direction arm.
- **Treat the engine's LAKE as the install's Coast** (lake-is-coast) — TS `=== 'COAST'` and GPU `water & ~ocean` agree at sea and differ on a lake. Spell shallow water as `isWater(t) && terrain !== 'OCEAN'` on TS and sweep `=== 'COAST'` hits against their GPU twins.
- **Guard the array side of a set stored as a bitmask** (bitmask-hides-a-duplicate) — the GPU's `|=` is idempotent where TS pushed a second University and paid it twice. When cardinality differs, write the membership guard on the array side, poke a double add, and sweep "who else writes this collection".
- **Count the catalog before writing a JS bitmask** (js-bitmask-32-bits) — JS bitwise ops are int32, so past 32 rows the read, write, popcount and exporter all alias while the int64 GPU twin stays right. Use `2 ** i` behind named helpers and sweep the tests' own mask code too.
- **Reference roster members by id, never array position** (wire-position-vs-id) — TS compacts `state.cityStates` on capture while the GPU is id-indexed, so later indices address a different member; a TS tie-break on unit id forked from a GPU tie-break on slot once a re-seated unit kept an old id. Grep wire appliers for `state.<roster>[k]` and any `u.id <` ordering.
- **Translate a district queue code through the scaffold** (queue-code-is-a-scaffold-slot) — `DISTRICT_BASE + si` indexes `_scaffold`, not `districts_cat`, so a row exported as a district index paid the wrong district. Translate with `_scaffold_di[...]` and pin a near-miss whose slot number collides.
- **Gather over the whole batch, then narrow** (narrow-batch-gather) — `plane.gather(1, tile[sel])` reads batch rows `0..n-1`, the wrong games, with no error; B=1 green and B=N red is this, not float noise. Write `plane.gather(1, tile.unsqueeze(1)).squeeze(1)[sel]`, pass `rows` to every batch-wide helper, and vary batch composition when hunting; `--seeds a,b` runs in ascending seed order.
- **Never use a `.any()`-reduced roster mask as a value** (collapsed-roster-mask) — `_row_is(...).any()` inside a `sum` paid one game's unique to every game in the batch; only a shard mixing carrier and non-carrier reds. `bool(...)` as a skip guard is fine if the body re-gates per game; `seat_symmetry_check.py::collapsed_roster_masks` refuses the value form.
- **Assert the dtype construct, never f32-vs-f64 agreement** (dtype-equality-not-invariant) — accumulators differ from turn 1 and every threshold eventually lands differently. Assert e.g. `sim._tiebreak_key_dtype == torch.float64`; a divergence between dtypes is not a bug, one between TS and GPU at the same dtype is.

- **Call the composer, never re-spell its sum** (two-composers-of-one-fact) — `holySiteFaith` re-assembled the Holy Site's faith that `cityDistrictYields` composes, so the Stave Church's Woods term reached one reader only; inline state predicates dropped `governorAt`'s neutralize clock; the city-strike defence was assembled inline twice and both copies lost `formationCS`. A reader of another rule's output calls that rule's composer (a case that cannot gets a SECOND NAMED composer, never an inline copy); before adding a term, count the GPU's occurrences of the FORMULA, since it may have no named helper. One function on one side against N inline sums on the other is itself the finding.

## Planes, masks and the wire

- **Dispatch appended enums by name, never by derived position** (append-shifts-derived-layouts) — appending an improvement shifted every action column laid out after the build columns, so both engines no-op'd pillage identically and a driver constant ordered the wrong verb. Grep for bare integers compared against action codes and length-derived offsets, and pin a new verb as `indexOf(prev) + 1`, not "last column".
- **Diff a cleared clone when a static fact becomes mutable** (baked-derivations-of-a-new-mutable) — harvest removed a resource from a workable tile and 18 exporter flags baked from `t.resource` went stale. The exporter reruns the record builder over `{...t, resource: null}` and ships the differing keys as `nr`; then sweep `_MUTABLE` and the statecompare manifest and re-read inherited exclusion reasons.
- **Derive plane lists from the registry, never transcribe them** (new-plane-misses-every-list) — a new occupancy or city plane was missed by hand-written scan, compaction and reset lists, handing a moved city's facts to its neighbour. Derive walks from `_MUTABLE` by geometry, keep per-slot state in a registered plane (never a side dict), and grep hand-rolled copies of a split's shape (`if civilian: ... else: military`).
- **Widen a boolean relation plane into one signed code** (boolean-plane-two-facts-short) — when a bool pair plane needs a second axis (which kind, who declared), encode `+(code+1)` / `-(code+1)` in one plane read through one-line predicates; a twin plane is one more thing to clear at every peace or elimination site.
- **Give an unconditional term its own plane** (term-inside-a-gated-plane) — a subtraction put inside `_seat_tile_add` inherited `_tile_add_any` and `has_bel` gates, so a seat with no adds was never charged (9196 t2). List the gates of a plane's consumers before piggybacking on it.
- **Give a named sentence its own plane** (comment-wider-than-formula) — `civilian`'s comment claimed `unitIsNoncombat`'s set while its formula excluded support chassis without charges, and seven GPU rules used `~_type_civilian` as "military". Read the expression under the comment, check whether the sentence is already on the wire (`military`), and read it by name.
- **Diff a plane's readers against each other** (data-right-reader-short) — three layers of one ladder were a correctly written plane with one consumer asking a question too few (`districtComplete`, `_type_civic`, `res_stripped`). Grep the plane and compare every use; fold facts spelled several ways into one predicate per engine.
- **Read wire keys hard at the exporter's path** (loader-get-wrong-level) — `r.get("workshopBidx", -1)` at the top level, where the exporter writes it under `seats`, defaulted for every game while the census saw the literal on both sides. Use `r["level"]["key"]` unless the default is a modelled absence, and poke that plants the channel and reads the yield.
- **Grep the wire before choosing a metadata key** (tag-key-collides-with-wire-field) — a provenance key `src` collided with a real adjacency field and a deep strip deleted it. Strip at the leaking spread, guard on the value's shape, and keep the rules.json md5 check around any change that claims to be inert.
- **Clone a memo key and version the catalog it reads** (memo-key-hazards) — a key stored as a view of a live plane compares equal to itself forever; a "pure" function also reads catalogs a poke can rewrite. `.clone()` stored keys and carry a catalog version in the key; the poke pool, not the gate, reaches the rewritten-catalog regime.
- **Stamp a fixture-time memo with `tensor._version` plus id** (version-counter-is-the-stamp) — `_gen_ver` counts unit generations and moves many times a turn. Grep what bumps a counter before keying on it; planes written mid-turn from many sites take an input fingerprint instead.
- **Keep derived constants in a leaf module** (import-order-nans-a-constant) — a const computed across an import cycle read undefined after an import was added, exported as `null`, and killed the GPU at construction. Put derived constants in `cpu/data/constants.ts`, and after touching `cpu/export/rules.ts` imports spot-check a cyclic scalar for null.
- **Give an optional field one named default** (optional-field-two-defaults) — `outerHp ?? 0` and `?? WALLS_HP` answer different questions and a third reader picks wrong; `movesFull` had the same shape. Fold defaults into one helper, write the field wherever the value is decided (creation included), and prefer a required parameter that breaks every caller at compile time.

## Instruments, probes and logs

- **Print the same primitive from both engines side by side** (same-step-both-engines) — six theories about a religion red died before a two-line print showed a step costing 4 on TS and 16 on the GPU: an embark arm reused a composed land cost that carried a river term. Print the primitive before reading either body; when a new arm appears, decompose the cost rather than reuse it.
- **Key a two-sided log on the decision, with every distinguishing field** (log-key-names-the-decision) — last-wins pairing makes a colliding key print one event against another; an edge-keyed step log, a missing sequence row and a writer tag in the value each produced a false reading. Key on order/anchor/writer, print refusals on both sides, window by turn, sort keys numerically, and cap per kind.
- **Ask whether the row paired before reading a field's silence** (census-key-hides-moved-rows) — the unit census keys on `tileIndex * 4 + stackSlot`, so a moved unit prints GPU-ONLY/TS-ONLY and compares nothing. A paired row's absent fields do agree; a divergence through an unreachable field needs a log keyed on something immutable.
- **Prove a probe fires before believing its silence** (probe-hygiene) — untagged interleaved games, ungated tensor rows, truncated windows, a nonexistent `state.seed`, a wrong schema key and a heredoc-broken patch each produced confident wrong readings. Tag by game id (`state.map.seed`), gate on the acting mask, anchor turn frames on a known event (statelog block N is the step run at `self.turn == N-1`), and `ast.parse` instrumented files.
- **Record a shared composer from one caller per engine** (probe-records-last-caller) — a probe on `computeCityStats` / `_seat_city_walk` records whichever caller ran last, and the engines' last callers differ. Use a `record` flag defaulted false set at one twin call site, and add a quantity that decomposes the compared one.
- **Treat a clean instrument as evidence about its patterns** (instrument-blindness) — adjacent-token patterns missed expression-level seat-0 forks; lane lists naming moved files, a nested digest shape that folded to NaN, and a positional decode of a tuple all shrank instruments silently. Ask what spelling of the fault the pattern misses, give hand-maintained lists a both-directions existence check, index cross-file contracts by name (`drive.DECIDE_FIELDS`), and re-derive summarising numbers by machine.
- **Return `[value]` from a one-row digest group** (one-row-group-folds-a-column) — a flat list made the fold hash element 0 only, symmetric and silent on both engines. Check `len(vals) == len(keys)` when adding a digest field; a new fold path needs the length guard too.
- **Name a census's roots before claiming a class closed** (census-roots-decide-the-claim) — `seat_symmetry_check.py` scanning only `gpu/core` + `policy` missed live literal-seat forks in TS, the world loader and the serve gate. Ask what lies outside the roots; the GPU scanner blanks string tokens, so literal dict keys need patterns for the blanked form.
- **Reason only from tool output that really arrived** (never-write-a-tool-result) — an emitted call plus a self-written result block led to a parity conclusion drawn from invented source. Duplicate line numbers or broken detail are the tell; re-run the read when in doubt.
- **Budget a serve hunt as a sequence of first-fire layers** (first-fire-layers) — each fix exposes the next mechanic firing for the first time in gate history; one hunt peeled sixteen. Rerun single-seed PAST the old red to 250, read the keyed diff (field names mechanic names twin bodies), and remember the civilian dump key (`2*tile+1`) does not name the unit type.

## What a green run proves

- **Ask which lane reaches a mechanic before believing a gate** (gate-reachability) — scripted parity was green across 24 seeds while zero Encampments were ever built. Answer reach from a run already happening or from a poke (never an extra rollout), smoke a roster row on a seed that seats its carrier, and build GPU lanes at B >= 2 since B=1 hides shape faults.
- **Run to the regime where the rules first differ** (smoke-scale-hides-divergence) — a 3-seed 30-turn check read 100% where 250 turns read 49%, because the two rules coincide while one unit is unlocked. Treat an early 100% as suspect; the expensive run is the measurement.
- **Measure every sibling path before fixing an asymmetry** (measure-every-path) — generalising one measured transfer path to all three turned one red into three with an inverted sign. Tabulate every path on both engines, characterise the reference rule, and revert a fix that raises the red count.
- **Rule a theory out in every path of the field** (theory-elimination-is-per-path) — an index-space bug "eliminated" in the issue path lived in the resolve path. List every read and write of the field and name the sites checked.
- **Don't bisect by toggling a trajectory-steering feature** (trajectory-bisect-lies) — disabling a feature changes which games get played, so green after disabling it can just mean the games wandered away. Diff both state logs from a checkpoint for the first differing value and read it literally.
- **Pair a byte-identical rollout with the battery for refactors** (one-driver-is-not-a-proof) — a refactor md5-identical on the rollout still redded parity through a cache bump only rival paths carried. The md5 is a fast pre-check; different drivers reach different code.
- **Re-check liveness predicates when the start state changes** (start-state-invalidates-liveness) — settler starts froze every city-less seat because both engines gated the turn (and the unit walk under it) on owning a city, and agreed perfectly. Separate "in the game" from "has an economy", make warm-ups DRIVE (`settle_all`), and give each phase its own per-game `active` gate: a batch-wide `if not active.any(): return` is not one ("green alone, red with any partner").
- **Widen the regime with presets and styles when hunting** (preset-gates-widen-reach) — world presets and driver styles reached islands, abundant and solo regimes that exposed latent forks, including an applier's sibling arm and a membership set built from effects. They are a hunting tool, not the round bar; from a mismatched combat-roll `diff`, solve for the CS delta before reading code (+-20 is one Flanking/Support, +-50 an aura).

## Refactors, sweeps and codemods

- **Grep the sentence when a class, row or plane is added** (new-class-invariant-sweep) — naval barbarians broke four sites that said "barbs are never naval"; a war head over minors split "at war with anyone"; a third occupancy plane left 2-of-3 readers; a classifier answering `'military'` by exclusion adopted the Spy; minors with a tech tree fell outside `range(n_majors)` folds. Grep invariant phrasing, default arms and N-1 plane scans, and read each site's actual twin.
- **Re-read comments that describe the old shape** (stale-sentence-not-wrong-math) — five of six defects in one ladder were a comment true when written ("only a major keeps a city list"). Grep `only a`, `never`, `always`, `both` near loop bounds and booleans, and take plane lists from the allocator, not the clearing sites.
- **Verify a mirror's cited TS function still runs, and check history before deleting** (stale-transcription-of-a-dead-oracle) — GPU machinery mirrored a deleted TS loop, open-gap markers described systems long built, and a self-written blocker named a plane that existed. Open the cited function and its caller; run `git log -S'<symbol>'` before calling an orphaned mirror a fabrication (a body deleted with its host is a regression to re-home); grep for X itself before writing "X has no carrier".
- **Route reads through predicates before swapping storage** (migrate-comparisons-before-storage, boolean-to-comparison-precedence) — replacing a boolean with a comparison turned `!x.claimed` into `!x.pantheon !== null`, always true, with tsc and tests green. Introduce named predicates while the old field exists (type-checked), then swap; grep `![\w.]+ [!=]== ` after, and hoist accessor calls that break narrowing.
- **Grep the changed line after every codemod** (codemod-progress-is-not-a-write) — a batched codemod that raises writes nothing after printing earlier subs as applied; loading one file twice drops the earlier section; a multi-line anchor can eat the neighbouring line. Anchor and replace one line, copy non-ASCII anchors from the file, assert `count == 1`, and grep one symbol per section plus the line after the anchor. A red that moves earlier after a fix is the fix breaking something.
- **Finish a rename with a boundary-free grep and the other language's reader** (vocabulary-purge-grep) — `\b` greps miss words inside identifiers, stale string-enum tags fall into else-arms, and a renamed JSON key read with `.get(key, default)` silently defaulted. Run `grep -rniE` over all trees and grep the other engine's reader by the literal string.
- **Never cite an AUDIT id in code, and check chapter members against code** (audit-ids-rot-across-files) — ids get reused for different items across numbering generations, and a chapter title outlives its members. Write the sentence the tag stood for; verify each AUDIT entry against the code, not its heading.
- **Grep the symbol and run pyright after a deletion** (ruff-misses-dangling-locals) — ruff F821 missed a dangling local in a ~450-line body, and F841 forgives `_names` unless `dummy-variable-rgx = "^_$"` (now set in `.ruff.toml`). Run `npx pyright` with the root config last, never `--project gpu`.
- **Keep method and data attribute names distinct across mixins** (data-attribute-buries-method) — `self._seat_row = tensor` in one mixin shadowed `def _seat_row` in another and nothing static saw it. `seat_symmetry_check.py::shadowed_methods` guards this; a new mixin name must be new across all of `gpu/core`.
- **Know what the typecheck does not cover** (scripts-not-typechecked) — code outside tsconfig's `include` once wrote `null` into every fixture after a field move while tsc and vitest stayed green. After moving a field, grep untyped consumers by hand; fixture byte-identity is the check that catches it.
- **Smoke-run early; a compile bar hides runtime breaks** (freeze-hides-runtime-breaks) — the GPU engine could not construct for rounds (`rules.cs` vs `rules.citystate`, a missing mixin argument, a `.get` on the wrong bag) under a compile-only bar. Run a short construction smoke, grep both directions across declaration boundaries, add new loader keys as hard reads, and prove a new check fails on its target bug before calling it green.

## Tests, fixtures and pokes

- **Grep every test tree for a list's name when it grows** (count-pins-live-elsewhere) — length and tail pins live in files unrelated to the feature, and a TS pin has a GPU twin vitest never runs. Grep the assertion's idea (`len(`, `.length`, "LAST") in both `tests/cpu` and `tests/gpu`, and pin the row under test or explicit positions instead of a count.
- **Expect five classes of test fallout from a new rng consumer** (reseed-fallout) — zero-draw rng pins, fixture-reachability asserts, roll-marginal combat scenes, positional unit picks and costs read as Infinity before the first draw all red with no engine bug. Probe the scene's premises first; pre-drain draws, force per-row flags, make scenes deterministic, select units by (type, seat).
- **Seat the civilizations a scene assumes** (roster-draw-scenes) — each fixture's trio is the seeder's draw, so "row 0 is Rome" is false on most seeds. Call `play(sim, row, "NAME")` before settling, or clear `row_civ` / `row_leader` for a scene whose reference carries no roster term; read a new red on a settled lane as a draw change first.
- **Keep poke stdout byte-identical across build-once/restore** (poke-build-once-audit) — `restore()` does not cover map facts outside `_MUTABLE`, plain-Python catalogs a scene replaces, `_bldg_version`, `_appeal_cache` or a second live sim. A changed stdout line is a scene leaking state; a shorter warmup must be measured (8 turns banks no government-turns); count `\r$` since editors rewrite these files to CRLF.
- **Revert `seeder/worlds.lock` only for EOL churn** (worlds-lock-genstamp) — genStamp hashes the raw bytes of the `world/` and `seeder/` sources, so a catalog change moves it for real (commit the regenerated lock) and a CRLF/LF flip from `git checkout --` moves it with no content change (restore the bytes, never regenerate). Count `\r\n` vs `\n` per stamped file to find the odd one out.

## Sourcing from the install and data rows

- **Ask the owner when a disposition is unsourced** (civ6-production-is-never-lost) — Civ 6 never discards production (a hidden per-city buffer, `productionBank` / `city_prod_bank`), the base game has a production queue, and a cancelled item keeps its progress while an invalidated one banks it. An UNSOURCED bullet is a reason to ask, and a search that only returns mods is inconclusive, not evidence of absence.
- **Re-source every row, not the ones that confess** (declared-gaps-are-not-the-gap-list) — rows declaring a gap were written by someone who read the source; silent rows carried invented yields and wrong magnitudes. Price a sourcing pass as all rows and record silent-row findings as their own AUDIT item.
- **Check the install's granularity before keying on an engine class** (engine-class-coarser-than-install) — engine `cavalry` spans light and heavy, so a light-cavalry clause would have paid Knights and Tanks on both engines. Compare `Units.PromotionClass` for every chassis in the class and add a sourced tag with one named reader (`isLightCavalry`).
- **Read the feature a rule names, not another rule's list** (borrowed-feature-list) — the Stave Church borrowed the movement rule's woods list and counted Rainforest (9040 t113). Export the one index the rule names, state a shared list's purpose, and pin the negative on both engines.
- **Grep for readers before designing a "buildable" item** (carried-but-never-read) — sourced items are often already carried (catalog column, exporter row) with no reader on either engine. Grep the constant and its readers across `cpu/`, `gpu/` and `cpu/export/`; that is a one-site job.
- **Follow a data row to the number it pays** (rows-behind-an-early-return) — mountain rows sat dead behind `tileYields`' early return and the GPU's `work_ok`, with twin tests pinning the zero; whole families were loaded and read by nothing. A family is shipped only when a test on each engine reads the number through the paying site; if a clause needs a fact no plane holds, price the plane (it must reach `_MUTABLE` and the manifest).
