# Engine audit — open work
THIS FILE IS A LIST OF OPEN WORK. A resolved item is DELETED, not annotated; what was fixed, when and why is the git log's job (`git log -S <id>` finds an entry's history).

**Format.** An entry is one topic: `- **<id>. <TITLE>.** Weight <n>.`, then one line per item, `  - <KIND> (<topic>): <the item>`. An item is one concrete open case or one unread rule, stated as an observation: recording, turn, subject, ours against the game's. The items of one topic stand together; a new item is a new line, never a clause joined to another by a semicolon. `fit, unread: <rule>` is a ported rule that matches the recordings while its source in the DLL is unread. `conflicting notes` marks observations of one case that disagree. The kinds:

- **BUILD** — buildable now from a sourced rule; names the symbols.
- **BLOCKER** — waits on another entry; names it.
- **ASK** — the source under-determines it; the owner rules (the ledger below).
- **LAB** — the live game answers it (`tools/civ6lab/SESSION5.md`, scene named). A rule the install carries no number for is inferred from what the live game does: a scene that varies its inputs and fits the observed outcome.

**Recordings.** The duels in use are `tools/civ6lab/runs/h1_duelq{1117,1121,1124,1127,1128}_20261108T234731Z`. A citation stands as its finder wrote it: `duelq1124 t84` names that dump, another prefix (dueld, duelp, duelu, duelv, duelw, duely, duelz) an older dump of the same seed whose turns may differ, and a bare seed names no dump.

**RULES (owner):**
- Anchor code BY SYMBOL, never by line number.
- VERIFY-BEFORE-IMPLEMENT against a real Civ 6 source: the owner's install (XML over civilopedia; Base <- Exp1 <- Exp2, take the last) first, the live game second, forums last. An unsourced magnitude is an ASK, never an invention.
- A gap deferred on an unbuilt mechanic is TWO open items: the mechanic and the gap naming it. "Recorded" and "descoped" are deferrals, never closures.
- Every new mechanic records which lane REACHES it; a green gate over an unreached mechanic proves nothing.
- When an entry closes, delete its row and its entry in the SAME commit. An entry holds only its open items: no narrative of what is done (the commit, dll_readings.md and the code say that).
- The DLC packs' civilizations are ported later (C-131).

**State:** P8 training PARKED until this file is empty.
